# Controle-Inteligente-2026-1

## Resumo

Este projeto apresenta o desenvolvimento de um software para análise e controle de sistemas dinâmicos, no contexto da disciplina de Controle Inteligente. A aplicação é capaz de processar dados de entrada e saída, estimar o comportamento do sistema, aplicar técnicas de filtragem e modelagem de ruídos, além de implementar diferentes estratégias de controle, como controladores PID e PID Adaptativo. O sistema também dispõe de uma interface interativa para visualização em tempo real e ferramentas para avaliação de desempenho por meio de métricas quantitativas.
